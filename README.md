# Third Person Shooter Game

A third-person shooter game built with Unreal Engine, featuring immersive gameplay, custom characters, and dynamic environments. This project leverages Unreal Engine's Blueprint system, custom assets, and advanced animation workflows.

## Features

- **Third-Person Perspective:** Play from an over-the-shoulder view for immersive action.
- **Custom Characters & Animations:** Includes Mixamo and Mannequin character assets with unique animations.
- **Dynamic Combat System:** Fire, aim, crouch, sprint, and switch weapon states with responsive controls.
- **Interactive Environments:** Doors, interactables, and destructible objects for engaging gameplay.
- **Visual & Audio Effects:** Realistic muzzle flashes, footsteps, weapon sounds, and VFX for enhanced experience.

## Getting started

### 1. Clone the repository

```bash
git clone https://github.com/Benjaminax/Third-Person-Game.git
cd Third-Person-Game
```

### 2. Open in Unreal Engine

1. Launch Unreal Engine (recommended version: 5.x or later).
2. Open `ThirdPersonShooter.uproject` from the project root.

### 3. Configure project settings (if needed)

- Adjust input mappings in `Config/DefaultInput.ini` as desired.
- No environment variables required.

### 4. Run the game

- Click **Play** in the Unreal Engine editor to start the game.

### 5. Package/Build for distribution

- Use Unreal Engine's **Package Project** option for your target platform.
